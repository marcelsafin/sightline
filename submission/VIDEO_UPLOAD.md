**Title**
Sightline — the human-approval layer between an agent and a live page (WebMCP)

**Description**
An agent finds what holds a page back, drafts the fix, and stops. Nothing ships until you say yes — inside the page, with the exact change in view.

Sightline exposes nine WebMCP tools across three rule packs (accessibility via axe-core, SEO, performance). The agent authors alt text, labels and roles itself via needs_input; the engine measures contrast, heading levels and image dimensions from the live DOM. Every apply_fix pauses the tool call until a person approves. 23 problems → 100 / 100 / 100, then export only the approved work.
